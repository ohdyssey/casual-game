네이밍 규약 & 내보내기 규칙

키 네이밍
  • 업로드 이미지 키 접두 up_ (에디터 규약). 예) up_Pickmeup_CAR_blue
  • 차량 up_Pickmeup_CAR_<색> · 버스 up_Pickmeup_BUS_<색> · 승객 up_Pickmeup_PAX_<색>
  • UI 공통 up_Pickmeup_UI_<NN> · 배경 up_Pickmeup_BG_01
  • 매니페스트 public/ui-assets.json 에 "키":"ui/uploads/파일.png" 로 등록(에디터가 자동 갱신).
  • 로딩 화면은 고정 파일명: public/loading/{bg,logo,start_on,start_off}.png
내보내기 (에디터가 자동으로 안 지켜줌)
  • 스프라이트 시트 한 변 ≤ 2048px (구형/저가 모바일 안전).
  • GPU 메모리 = 가로 × 세로 × 4 (파일 용량과 무관!) → 화면 표시 크기에 맞춰 최소화.
  • 업로드 이미지는 표시 크기의 2배 해상도 이내. 과대 이미지 금지.
  • 투명 배경 PNG. 차량/버스는 진행방향 ▲ 위(north) 기준으로 통일.
  • export 후 개발자가 PNG→WebP 최적화. PNG 재내보내면 최적화 재실행 필요.
작업 흐름 — ① 이 보드로 "무엇을" 그릴지 확인 → ② 이미지 제작 → ③ phaser-ui-editor 로 이 폴더를 열어 업로드·배치(SSOT public/ui/layouts/main.json) → ④ 게임 dev 서버(npm run dev:pickmeup, 포트 6206) 새로고침으로 즉시 확인. 레이아웃이 비어 있는 동안은 게임이 라벨 플레이스홀더를 보여준다(부팅 OK).
