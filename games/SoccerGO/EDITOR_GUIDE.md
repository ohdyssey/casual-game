# phaser-ui-editor 작업 가이드

> 이 폴더의 화면은 **phaser-ui-editor(GameDevTool)** 로 디자인합니다(SSOT).
> 저장본: `public/ui/layouts/*.json`(레이아웃) · `public/ui/sprites/*`(스프라이트) · `public/ui/uploads/*`(이미지) · `public/ui-assets.json`(매니페스트).
> 코드는 이 디자인을 그대로 렌더하고 **동작만** 얹습니다. 화면/효과는 여기(에디터)서 만드세요.

---

## 1. 화려한 효과는 에디터에서 — 런타임이 자동 재생합니다
노드 또는 폴더(그룹) 선택 → **애니메이션 패널**에서 효과를 겁니다. 게임 실행 시 자동 재생(코드 불필요).

| 카테고리 | 종류 | 용도 |
|---|---|---|
| **트윈** | 맥동·통통·흔들·깜빡·회전 | 버튼·아이콘·로고에 생기 |
| **스프링** | 탄성 | 등장/누름의 쫀득한 반동 |
| **파티클** | 방출 | 노드 위 반짝임·연기·불꽃 |
| **스프라이트** | 프레임 클립 | 캐릭터 동작(예: 골키퍼 다이빙) |

- **트리거**: `상시(idle)`=루프 · `등장(enter)` · `누름(tap)` · `퇴장(exit)` · `값변경(dataChange)`
  - 현재 런타임은 **idle + enter 를 자동 재생**합니다. `tap`/`exit` 는 코드 연결이 필요 → 개발자에게 요청하세요.
- 폴더(그룹)에 효과를 걸면 멤버에 일괄 적용됩니다(개별 노드 효과가 우선).
- ⚠️ **`wind`/`grasswind`(바람) 대신 `흔들(sway)` 사용.** wind 는 런타임에서 sway 로 자동 강등됩니다(정식 지원 아님).

## 2. 캐릭터 애니메이션(스프라이트 시트)
스프라이트 에디터에서 시트를 슬라이스한 뒤 노드를 **spriteDocClip** 으로 배치하면 자동 재생됩니다.

## 3. ⚠️ 에셋 내보낼 때 반드시 (에디터가 자동으로 안 지켜줍니다)
- **스프라이트 시트 한 변 ≤ 2048px** — 구형/저가 모바일에서 안 깨지게. 프레임이 많으면 한 줄로 길게 말고 정사각에 가깝게 행/열 분할.
- **GPU 메모리 = 가로 × 세로 × 4 (파일 용량과 무관!)** — 프레임 수·해상도를 *화면에 보이는 크기*에 맞춰 최소화.
- 업로드 이미지는 화면 표시 크기의 **2배 해상도 이내**면 충분 — 과대 이미지 금지.

## 4. 에디터 vs 코드 — 무엇을 어디서
- **에디터**: 레이아웃(배경·HUD 패널·로고) + 노드에 붙는 효과(맥동/흔들/파티클/스프라이트, idle/enter/tap).
- **코드**: 게임플레이 오브젝트(공·수비벽·골키퍼)와 그 순간 그 좌표에 터지는 동적 VFX(슛 궤적·골 컨페티) —
  레이아웃 노드가 아니라 런타임 좌표라서. `src/scenes/PlayScene.ts` 참고.

## 5. 저장 후 확인
1. 에디터에서 저장 → 게임 dev 서버(포트 6210) 새로고침으로 즉시 반영.
2. 효과가 안 보이면: (a) 종류가 '없음'인지, (b) `wind` 류인지(→ `흔들`로 변경), (c) 트리거가 `tap`/`exit` 인지(→ 코드 연결 필요) 확인.
