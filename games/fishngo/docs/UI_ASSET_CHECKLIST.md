# UI 자산 체크리스트 — 필수 공통 아이콘 / UI 세트

세로형 낚시 게임(Phaser 3)의 **공통·재사용 UI 디자인 자산** 목록. 각 화면(Home / Fishing / Result / Album / Shop / Upgrade / Loading)과 데이터 시스템(장비·재화·70종 도감·10지역·50스테이지)을 감사해 **현존 vs 신규 필요**를 구분하고 **권장 픽셀 크기**를 제시한다.

> 범례: ✅ 현존(에셋 키 있음) · 🆕 신규 필요 · ♻️ 기존 자산 재사용 가능
> 우선순위: **P0** 핵심 루프 필수(현재 플레이스홀더/이모지로 때우는 중) · **P1** 중요 · **P2** 폴리시

## 0. 공통 규격 / 제작 지침

| 항목 | 지침 |
|------|------|
| 기준 해상도 | **720×1280 (세로)**. 표의 px는 이 기준. scale.js가 반응형 스케일 처리 → **디자인 px로 작업 후 @2x/@3x 내보내기** |
| 포맷 | **WebP 전용**(프로젝트 규칙). ⚠️ 현재 위반 PNG 일괄 변환 필요: `tile_frame_*`, `icon_item_*`, `icon_menu_*`(UI_37~46), `fish_gauge_*`, `Loading_*` |
| 터치 영역 | 시각 크기 ~56px여도 **히트영역 ≥88×88px** 확보(Phaser는 스프라이트보다 큰 히트렉트 허용). 현재 닫기버튼 44px → 56px로 확대 |
| 크기 티어 | **마이크로 <28**(레드닷 18·페이지닷 16·별핍 20) / **인라인 28–32**(등급·레벨·스탯·체크) / **유틸 40–48**(정보·정렬·±·공유) / **기본 디스크 56**(닫기·뒤로·사운드·일시정지·광고▶) / **히어로·상태 64–72**(상자·스탬프·손·스테이지노드) / **하단내비 95** / **슬롯 120** |
| 9-slice | 패널·헤더·행·버튼·토스트·말풍선은 9-slice. **코너/엣지 inset 명시**(28px 라운드 패널 ≈ 24px 코너, 카드 ≈ 16px) → 늘려도 코너 안 깨지게 |
| 컬러 | 따뜻한 캐주얼 팔레트 고정(신규 색조 금지): 크림 `#fff8e7` · 브라운 `#8b5a3c` · 헤더 `#ffe5a8` · 그린 `#45c34c` · 오렌지 `#ff9a3c` · 레드 `#e74c3c` · 골드 `#ffd147`/`#a35a00` · 젬 `#7cd5ff`/`#1e7fb8` |
| 네이밍 | 기존 prefix(`btn_/hud_/bar_/meter_/item_/tab_/panel_/icon_`) 확장 + 신규 family: `badge_*`(레드닷·카운트·지역·등급·리본) · `fx_*`(코인버스트) · `node_*`(스테이지맵) · `toggle_*`(사운드/뮤직/진동) · `overlay_*`(잠금·장착·비활성·체크). 상태는 **접미사**로(`_default/_pressed/_disabled/_locked/_active/_on/_off`) → 코드가 문자열로 스왑 |
| 상태 전략 | 거의 모든 자산이 현재 static/pressed뿐. **disabled / locked / active(selected)** 를 1급 상태로. 베이스마다 다시 그리지 말고 **재사용 오버레이 1세트(잠금·체크·비활성틴트·선택링)** 를 베이스 위에 얹기 |

### 🎯 최우선 단일 자산 (4+ 화면 재사용, 가장 높은 레버리지)
1. **자물쇠(padlock)** — 도감·지역·스테이지·상점 게이트 전부 (지금 ❓ 이모지/단색 틴트로 대체 중)
2. **체크마크(check)** — 퀘스트완료·장착·설정ON·일일수령·스테이지클리어 공용
3. **레드닷 + 카운트 배지** — 미수령 보상·신규 퀘스트·일일·상점·신규도감 재참여 동력
4. **지역 배지 ×10** — 도감 필터·스테이지맵·"X지역에서 낚기" 퀘스트의 연결 조직
