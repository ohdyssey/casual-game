# 꼬치왕 레벨 설계 (Level Design)

> 단일 진실 공급원은 [src/logic/levels.ts](src/logic/levels.ts). 이 문서는 그 설계 의도와 커브를 설명한다.
> 보드 규칙은 [src/logic/board.ts](src/logic/board.ts), 데이터 타입은 [src/logic/types.ts](src/logic/types.ts).
> 해결가능성 회귀 테스트는 [src/logic/solvability.test.ts](src/logic/solvability.test.ts).

## 1. 한눈에

- **장르**: 그릴 위에서 같은 꼬치 3개를 한 불판에 모아 서빙하는 정렬형 3-매치 퍼즐.
- **보드**: 3열 × 4행 = 그릴 **최대 12칸**. 각 칸은 슬롯 3개 + 대기 큐(쟁반). 이동은 인접이 아니라 **전역 드래그**(어느 그릴 → 어느 그릴이든).
- **레벨**: **1~300** 단일 커브(총 600 설계 중 우선 300). 모든 레벨은 레벨 번호의 함수로 결정적 생성.
- **승리**: 제한 시간 내 목표 꼬치 수(`targetSkewers`) 서빙. **실패**: 시간 초과 / 교착 / 재료 소진.
- **불변식(가장 중요)**: **모든 레벨은 반드시 풀 수 있다.** `clampForSolvability` + 생성 규칙 + 300레벨 전수 시뮬레이션으로 보장.

## 2. 난이도 커브 (레벨 → 파라미터)

레벨이 오를수록 각 레버가 **미세하게** 상승한다(`levels.ts` 의 `*For(lv)` 함수). 대략:

| 레버 | 필드 | 커브 | 비고 |
|------|------|------|------|
| 그릴 수 | `layout`/`lockedGrills` | **9칸**(L1) → **20레벨마다 +1** → 12칸(L61) | 저레벨=상단 잠금, 고레벨=그릴 많음 |
| 종류 수 | `typePool.length` | 4 → 최대 16 | **보드 크기·세트 수로 재상한**(작은 보드에 종류 과다 방지, 종류 ≤ 세트) |
| 목표(세트) | `targetSkewers` | 12 → 72(24세트) | 3의 배수. 판 길이 |
| 제한 시간 | `timeSec` | 목표에 비례(넉넉) − 레벨 상승분 | 후반일수록 조인다 |
| 고정(메뉴고정) | `pinnedCount` | **L25 도입** → ~25레벨마다 +1(≤4) | 초반엔 없음 |
| 숯(메뉴 빈곳) | `charredCount` | **L45 도입** → ~30레벨마다 +1(≤4) | 초반엔 없음 |
| 2겹 숯 | `charLevel` | L110+ = 2 | 인접 매치 2번 필요 |
| 보드 모양 | `layout` | L61+ 만석 후 **5레벨마다 이형(구멍)** | 변주 |
| 버퍼 | `bufferSets` | 기본 2, L25+ 6의 배수는 1(빡빡) | 재료 총량 = 목표 + `bufferSets`×3 |

## 3. 그릴 개방 (progressive unlock)

- **9칸으로 시작**(상단 3칸 잠금 = `lockTop`). 잠긴 칸은 "🔒 Lv N"(개방 레벨) 표시.
- 레벨이 오르면 **20레벨마다 상단 칸이 하나씩 열린다**(L21·L41·L61). 즉 **추가 그릴은 위쪽에 배치**되고 활성 영역이 위로 자란다.
- L61에 12칸(만석). 이후 그릴 수는 이형 보드(구멍)로만 변주.

## 4. 특수 칸

- **📌 고정(pinned)**: 슬롯0 에 고정된 꼬치(뺄 수 없음). 같은 종류 2개를 더 가져와 완성. ⚠️ 고정 그릴은 절대 비지 않아 리필이 안 걸리므로 **큐를 배정하지 않는다**(안 그러면 큐 꼬치가 영구히 갇혀 승리 불가).
- **🔥 숯(charred)**: 슬롯2 를 막는 방해. 그 그릴에선 매치 불가 → **인접 그릴에서 매치하면 냉각**(charLevel 만큼). 항상 "매치 가능한 인접(비-숯, 미잠금)"이 있는 내부 칸에만 배치(코너 회피·서로 고립 금지).

## 5. 해결가능성 보장 (`clampForSolvability`)

시뮬레이션으로 확인된 "구조적으로 못 푸는" 원인을 마지막에 보정한다:

1. **고정 그릴 큐 잠금** → 큐는 고정 아닌 그릴(자유·숯)에만 분배(`generateBoard`).
2. **방해 과다** → 플레이 가능 칸 대비 **숯 ≤ 25%, 고정 ≤ 33%**, "숯도 고정도 아닌 자유 그릴" 최소 확보. 초과분은 고정→숯 순 감축.
3. **종류 > 세트** → 종류를 세트 수 이하로 캡(재료 총량 = 목표+버퍼 유지).
4. 방해가 빽빽하면 버퍼 +1(라우팅 여유).

**검증**: [solvability.test.ts](src/logic/solvability.test.ts) 가 대표 레벨(16시드)과 **전 300레벨 전수 스윕**을 휴리스틱 솔버로 실제 플레이해 전부 승리함을 확인 + "고정 그릴 큐=0" 불변식 검사.

## 6. 씬/UI 연동 ([src/scenes/GrillScene.ts](src/scenes/GrillScene.ts))

- 코드가 3×4 그릴 그리드를 직접 그린다(에디터 정적 그릴 grp_2/3/4 는 숨김). 활성/잠김/이형은 `layout`+`lockedGrills` 로 렌더.
- **하단 1번 버튼 = 홈(로비)**, **하단 맨 오른쪽 = 레벨 선택 메뉴**([levelSelect.ts](src/scenes/levelSelect.ts), 열린 레벨 1..세이브레벨). 다음 레벨/재도전/레벨 선택은 `scene.restart({ level })` 로 명시 레벨 시작. 승리는 최고 레벨을 되돌리지 않는다.
- **특별주문(특별 미션)**: 이 레벨의 **메뉴(typePool) 중에서만** 주문하고, **레벨이 오를수록 더 자주** 등장(간격 최대 60% 단축).
